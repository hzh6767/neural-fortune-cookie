# Neural Fortune Cookie

A tiny offline AI-style fortune generator. It mixes a selected mood with playful local phrase banks to produce absurdly specific predictions.

## Run

Open `index.html` in any modern browser. No build step, server, network connection, or API key is required.

## Features

- Responsive form with name, mood, and optional question
- Locally generated fortunes and a four-item in-session history
- Copy-to-clipboard action when supported by the browser
- Keyboard-friendly controls and live result announcements
